# ORACLE troubleshooting

- **Install menu:** open ORACLE while connected, then use the browser install command. iPhone/iPad: Safari → Share → Add to Home Screen.
- **Update:** finish active scans and save Field desk notes before applying. ORACLE warns before reloading this tab; other tabs are not forced to reload.
- **Offline:** saved readings, Field desk notes, and explicitly queued information-only requests remain on the device. Live actions require a connection and are reviewed before sending.
- **Camera:** allow camera access, or use the displayed manual code/image fallback.
- **Access denied or expired session:** sign in again and confirm current event membership.
- **Large group sign-in:** the shared-IP limit is 60 combined registration/login attempts per 15 minutes. Pre-register and sign in ahead of time or stagger arrivals.
- **Recovery:** do not reset a live event. Use the deployment and recovery runbook; scheduled production backups are not currently configured.
