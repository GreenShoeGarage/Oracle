# ORACLE v1.0.0

This release completes the production handoff for the v1.0 software release. It includes the three starter adventures, all twelve instruments, theme-aware event packs, character and QR workflows, offline Field desk support, accessible onboarding, safe rehearsal reset, and documented recovery procedures.

Verified on the deployed release: PostgreSQL CI, recovery/startup/image checks, isolated 100-player bursts, all twelve instruments across Fantasy/Cyberpunk/Wasteland, staging and production readiness, and 70 public GET paths. The existing project superuser remains enabled.

The physical-device and human pilot remains an explicit follow-up acceptance gate. Sustained Railway capacity and scheduled live backups are not claimed by this release.
