# ORACLE theme and event packs

Themes change presentation and vocabulary. Rules, resource IDs, permissions, and outcomes remain stable. The shipped themes are Fantasy, Cyberpunk, and Wasteland.

Format-1 briefing packs contain event setup: theme, enabled instrument choices, bounded rules definitions, and briefing material. **Export organizer briefing pack** includes private organizer briefing notes; keep it private. **Export player material** removes organizer-only briefing content. Import validates the pack and creates a separate Draft event.

These packs do not include characters, adventure/instrument definitions or progress, inventory, balances, trades, story publications, investigations, encounter operations, account records, or a database backup. Exporting a pack cannot preserve or restore a complete played event. See [deployment and recovery](DEPLOYMENT.md) for database backup limitations.

Starter adventures create separate event drafts with fresh identities and codes. Use **Make rehearsal copy** to practice a configured adventure. Reset is available only on a dedicated rehearsal copy and restores its captured starting state; it cannot reset a live event or its source. A rehearsal copy stays within ORACLE and is separate from briefing-pack export.
