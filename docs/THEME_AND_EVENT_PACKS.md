# ORACLE theme and event packs

Themes change presentation and vocabulary. Rules, resource IDs, permissions, and outcomes remain stable. The shipped themes are Fantasy, Cyberpunk, and Wasteland.

An event pack contains the authored briefing, instruments, characters, story, economy, and operations for one event. Use **Export organizer briefing pack** for setup material and private notes; keep it private. **Export player material** removes organizer-only content. These are not database backups.

Starter adventures are separate event drafts with fresh identities and codes. Use **Make rehearsal copy** to practice. Reset is available only on a dedicated rehearsal copy and restores its captured starting state; it cannot reset a live event or its source.
